# Mock Interview Rounds 9–15

## Round 9 — Security Interview

**Target duration:** 50 minutes

### Prompts

1. Threat-model an API dashboard.
2. Explain XSS sinks, CSP and Trusted Types.
3. Explain why CORS is not authorization.
4. Review token/storage and third-party dependency risks.

### Scoring rubric

- Trust boundaries 35%
- Browser security 30%
- Mitigations 20%
- Communication 15%

### Pass signal

The candidate can state assumptions, derive behavior from language/host rules, identify failure modes, and explain at least one trade-off or test strategy. Senior/staff rounds require architecture and organizational consequences, not only syntax.
