# Mock Interview Rounds 1–8

## Round 1 — Junior JavaScript Screen

**Target duration:** 30 minutes

### Prompts

1. Explain `let`, `const`, and `var`.
2. Predict a coercion/equality snippet.
3. Write a small array transformation without mutation.
4. Explain a thrown TypeError from a property access.

### Scoring rubric

- Correct fundamentals 40%
- Clear reasoning 30%
- Working code 20%
- Communication 10%

### Pass signal

The candidate can state assumptions, derive behavior from language/host rules, identify failure modes, and explain at least one trade-off or test strategy. Senior/staff rounds require architecture and organizational consequences, not only syntax.
