# Learning Roadmap

Use this sequence on the first pass:

1. **Start Here + 01–08** — grammar, bindings, types, coercion, equality, operators, control flow, loops.
2. **09–17** — functions, execution, closures, `this`, objects, descriptors, prototypes, classes.
3. **18–30** — arrays, Unicode, numbers, dates, regex, symbols, collections, iterators, generators, typed/shared memory.
4. **31–47** — errors, Promises, async/await, event loop, async iteration, ESM, resource management, Proxy/Reflect, memory, JSON, Intl.
5. **48–62** — design paradigms plus browser DOM/events/forms/fetch/storage/timers/workers/security.
6. **63–77** — execution contexts, environment/reference records, abstract operations, Realms, Jobs, parsing, engines, JIT mental models, performance and debugging.
7. **78–97** — architecture, API/runtime validation, tooling, testing/races/error strategy, library/framework authoring, staff policy, history, ES2026, TC39, Annex B, spec reading, semantic case studies.
8. **Projects** — build all ten guided systems, then the capstone.
9. **Interview mastery** — use the 350-question bank and 15 mock rounds.

## Progression test

You are ready to move from a phase when you can:

- predict ordinary behavior without running the code;
- explain the mechanism using the correct layer (language, engine, host, tooling, application);
- debug a counterexample;
- name at least one performance/security edge;
- choose between alternatives based on trade-offs rather than preference.
