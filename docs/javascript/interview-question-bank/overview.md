# Interview Question Bank

This bank contains **384 numbered JavaScript interview questions** across **Beginner → Intermediate → Advanced → Senior → Staff / architecture**. Every numbered question includes its category, expected answer, reasoning, a common incorrect answer, a follow-up, and a related handbook chapter.

## Difficulty bands

- **Beginner:** Q001–Q075 — syntax, declarations, types, coercion, equality, operators, control flow, and core functions.
- **Intermediate:** Q076–Q150 — closures, `this`, objects, prototypes/classes, built-ins, and iteration.
- **Advanced:** Q151–Q225 — generators, binary/shared memory, errors, Promise/async/event-loop/modules, and metaprogramming.
- **Senior:** Q226–Q300 — browser APIs/security, language internals, engines, performance/debugging, testing, and race conditions.
- **Staff / architecture:** Q301–Q376 — API/error architecture, large applications, libraries/frameworks, staff governance, ECMAScript evolution, and specification reasoning.
- **Output prediction:** Q377–Q384 — executable snippets requiring mechanism-first explanations.

## How to practice

Answer aloud before reading the expected answer. For semantics questions, name the governing rule. For production questions, state ownership, failure behavior, cancellation, security/performance implications, and the evidence you would collect.
