# Q001–Q020
## Q001 — Define Automatic Semicolon Insertion precisely.
- **Level:** Beginner
- **Category:** Automatic Semicolon Insertion
- **Expected answer:** ASI inserts semicolons only at specific grammar points; line breaks can change parse results, especially before `(`, `[`, template literals, regex-like tokens, or after `return`.
- **Reasoning:** Tests the governing mechanism.
- **Common incorrect answer:** ASI simply adds a semicolon at every newline.
- **Follow-up:** Give one minimal example.

- **Category:** `let`/`const` hoisting and TDZ

## Q013 — Define `var` scope precisely.
- **Level:** Beginner
- **Category:** `var` scope
- **Expected answer:** `var` is function-scoped (or global-script scoped), is initialized to `undefined` during declaration instantiation, and does not create block scope.
- **Reasoning:** Tests the governing mechanism.
- **Common incorrect answer:** `var` behaves exactly like `let` except it allows redeclaration.

## Q017 — Define bindings vs values precisely.
- **Level:** Beginner
- **Category:** bindings vs values
- **Expected answer:** A variable binding is a named association in an environment; objects are values, and a binding can reference an object value without storing the object 'inside' the variable.
- **Reasoning:** Tests the governing mechanism.
- **Common incorrect answer:** Variables either contain primitives or pointers, as a language guarantee.
- **Follow-up:** Give one minimal example.
