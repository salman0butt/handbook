# JavaScript Logic-Building Track

This track contains **300 distinct problems**:

- [Beginner problems 1–100](./beginner-001-100.mdx)
- [Intermediate problems 101–200](./intermediate-101-200.mdx)
- [Advanced problems 201–300](./advanced-201-300.mdx)

Every rendered problem includes difficulty, category, statement, input, output, constraints, example, hint, recommended approach, complexity and an expandable solution explanation.

## Practice loop

1. Restate the contract and examples.
2. Identify boundary cases and an invariant.
3. Write a simple correct solution.
4. Test normal, empty, invalid and maximum cases.
5. Analyze time and space.
6. Improve only when constraints require it.
7. Explain the trade-off aloud as though in an interview.

The track progresses across arithmetic, strings, arrays, objects, functions, recursion, sorting, searching, collections, dates, regular expressions, async JavaScript, DOM, browser APIs, data transformation, state machines, caching, concurrency, architecture, debugging, security and performance.
