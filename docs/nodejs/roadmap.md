# Node.js Learning Roadmap

This handbook progresses from runtime foundations to production architecture. Learn sequentially on a first pass, then use the later chapters as an operational and interview reference.

```text
JavaScript developer
        ↓
Node.js beginner
        ↓
productive backend developer
        ↓
advanced Node.js developer
        ↓
senior backend engineer
        ↓
distributed-systems / platform engineer
        ↓
staff-level architecture and runtime reasoning
        ↓
production + interview mastery
```

## Stages

1. **Runtime foundations:** Node vs JavaScript, V8, libuv, process, modules, npm, event loop, timers, buffers, streams, files, events, HTTP and networking.
2. **Concurrency and parallelism:** async I/O, promises, cancellation, child processes, workers, process scaling, memory and V8 mental models.
3. **Backend engineering:** validation, REST, Express/Fastify/NestJS, databases, caching, queues, messaging, real-time systems, auth, authorization and cryptography.
4. **Production engineering:** testing, TypeScript integration, diagnostics, performance, observability, graceful shutdown, resilience, concurrency control, containers, Kubernetes and CI/CD.
5. **Architecture:** distributed systems, API/domain design, monoliths, microservices, serverless, platform standards, scaling and production incident reasoning.
6. **Mastery:** projects, 300+ interview questions, mock interviews, API coverage and a final completeness audit.

At every stage ask: **what code is running, on which execution resource, what is waiting, what can block, what can fail, and what changes under load?**
