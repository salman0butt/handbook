# Mock Interview Practice — 15 Rounds

The handbook contains the 15 required mock rounds:

1. SQL beginner
2. SQL intermediate
3. SQL advanced
4. joins + aggregates
5. window functions
6. schema design
7. indexing
8. transactions
9. concurrency
10. EXPLAIN
11. performance
12. PostgreSQL internals
13. production operations
14. senior system design
15. staff database architecture

## Global scoring rubric — 100 points per round

| Dimension | Points | What earns full credit |
| --- | ---: | --- |
| Correctness | 30 | Correct SQL/semantics/invariants; explicit NULL/tie/error behavior |
| Mechanism | 20 | Explains how PostgreSQL actually implements/executes the concept |
| Trade-offs | 20 | Compares alternatives and names costs/failure modes |
| Production reasoning | 20 | Concurrency, plans, migrations, security, recovery/ops as relevant |
| Communication | 10 | Structured answer, assumptions stated, validates with evidence |

**90–100:** strong senior/staff-level performance for the round. **75–89:** solid but has gaps. **60–74:** correct fundamentals but insufficient production depth. **Below 60:** revisit mapped chapters before retrying.

Use [Rounds 1–5](./rounds-01-05.md), [Rounds 6–10](./rounds-06-10.md), and [Rounds 11–15](./rounds-11-15.md). Record your score, the first wrong assumption you made, and one concrete chapter/exercise to repeat.
