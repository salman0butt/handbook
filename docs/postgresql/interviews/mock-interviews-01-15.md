# PostgreSQL Mock Interview Rounds

# Round 1: SQL Fundamentals

**Difficulty:** Beginner

1. Explain the mechanism without jargon.
2. Write or review executable SQL.
3. Diagnose a realistic failure.
4. Propose a reversible production change.
5. Defend schema, transaction, index, security, observability, backup, and scaling trade-offs.

Score 0–5: syntax recall; correct mechanism; executable solution; production evidence and rollback; cross-layer staff reasoning.
