# Reference and Coverage

Use this section to audit handbook completeness, stability labels, production assumptions, and specification coverage.

The completion matrix points to both the original focused curriculum and the gap-closing modules. The automated validator confirms the required source files, category indexes, version baseline, sidebar references, Mermaid fences, visible title quality, and absence of placeholder content.

A successful validator is necessary but not sufficient: framework APIs and production advice must still be reviewed against current official documentation when the baseline changes.
