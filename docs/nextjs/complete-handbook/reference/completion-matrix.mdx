## Audit rules

- App Router is the default; Pages Router is labeled compatibility-only.
- Visible sidebar labels contain no numeric chapter prefixes.
- External data is validated at runtime.
- Authorization is enforced on the server at the resource boundary.
- Caching and invalidation are explained wherever state can become stale.
- Mermaid diagrams must parse in the repository validator.
- Docusaurus build and internal links must pass before merge.

## Known boundary

Framework internals are educational models, not guaranteed public contracts. Preview features are isolated from the stable 16.2.x baseline and must be re-verified before production adoption.
